## 🚀 Featured Projects

### 1. [SnapURL](https://github.com/adarshisop/url_Shortner)

A URL shortening platform built using **Java and Spring Boot**, with authentication, analytics, and caching.

- 🔐 JWT authentication, role-based access control, and BCrypt password hashing.
- 🔗 SHA-256 and Base62-based URL generation with collision handling.
- ⚡ Redis integration for caching and URL expiration.
- 📊 URL analytics using JPQL.
- 📱 QR code generation using ZXing.

**Tech:** Java · Spring Boot · PostgreSQL · Redis · JWT

### 2. [CivicPulse](https://github.com/adarshisop/CivicPulse)

A civic complaint management platform designed to simplify complaint registration, tracking, and resolution.

- 📝 REST APIs for complaint registration and management.
- 🔐 JWT-based authentication and authorization.
- 📍 Duplicate complaint detection using location-based distance checks.
- 🗄️ PostgreSQL and Spring Data JPA for persistence.
- 🖥️ React-based frontend and administrative interface.

**Tech:** Java · Spring Boot · PostgreSQL · Spring Security · React
